# README image provenance

`blip-desk.png` is an AI privacy edit of the author's photograph of the working
printed prototype. Background monitor content was removed and LCD content
replaced with fictional demo items. It is not an exact screenshot of the firmware.
The original work photograph is intentionally not included in the repository.
The edit used the built-in imagegen tool. PNG metadata was removed without
changing the rendered pixels.

`blip-rear-shell.png` is an OpenSCAD render of `enclosure/v2/assembly.scad` with
`part="stand"`, showing the newer rear-shell walls and header-clearance slots.
That revision has not been physically printed and verified.
